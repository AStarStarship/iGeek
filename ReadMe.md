An AI sandbox  and game engine for building, measuring, and learning AI Agents in different environments running on parallel systems.

[![GitHub version](https://badge.fury.io/gh/KabukiStarship%2FiGeek.svg)](https://badge.fury.io/gh/KabukiStarship%2FiGeek)

## Mission and Vision

The mission of iGeek is to make it easier to facilitate the build, measure, and learn feedback cycle with a bare-metal to the cloud pipeline. The vision of iGeek is to create a portable robotics simulator that can also be used for games and scientific computing.

## Organization

iGeek is built with [Script2](https://github.com/KabukiStarship/Script2), [Kabuki Toolkit](https://github.com/KabukiStarship/KabukiToolkit), and [ScriptTek](https://github.com/KabukiStarship/ScriptTek).

1. [GraphWorld](https://github.com/KabukiStarship/GraphWorld) - A mathmatical plotting environment.
1. [iGeekUlator](https://github.com/KabukiStarship/iGeekUlator) - An IMUL graphing Calculator iGeek extension.
1. [TileRPGWorld](https://github.com/KabukiStarship/iGeek.gitTileRPG) - A role-playing game TileWorld extension.
1. [TileWorld](https://github.com/KabukiStarship/iGeekTileWorld) - A 2D tile game engine.
1. [TileCarWorld](https://github.com/KabukiStarship/iGeekTileCarWorld) - A TileWorld car autopilot.
1. [PolygonWorld](https://github.com/KabukiStarship/iGeekPolygonWorld) - An abstract simulation of viruses.
1. [VirusWorld](https://github.com/KabukiStarship/iGeekVirusWorld) - An abstract simulation of viruses.
