A 2D tile world environment for [iGeek](https://github.com/AStarStarship/iGeek).

Status: **infrastructure** — TileWorld provides shared map/occupancy
primitives (TileMap, occupancy, collision) used by CarWorld, BikeWorld,
and PacWorld. Not an RL environment; no Gym subclass, no PPO loop.
