# iGeek Cookbook

By [Cale McCollough](https://cookingwithcale.org)

Worked examples and getting-started notes for the [iGeek](../) AI gym: a
no-stdlib C++23 headless engine for building, measuring, and learning agents
in parallel fuzzed environments.

You can watch the iGeek Cookbook videos and find extra content on YouTube at:

 https://www.youtube.com/channel/UCS2vQG4gUE3vXWV_K9XScQw
