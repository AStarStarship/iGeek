An AI sandbox  and game engine for building, measuring, and learning AI Agents in different environments running on parallel systems.

[![GitHub version](https://badge.fury.io/gh/AStarStarship%2FiGeek.svg)](https://badge.fury.io/gh/AStarStarship%2FiGeek)

## Mission and Vision

The mission of iGeek is to make it easier to facilitate the build, measure, and learn feedback cycle with a bare-metal to the cloud pipeline. The vision of iGeek is to create a portable robotics simulator that can also be used for games and scientific computing.

## Organization

iGeek is built with [Crabs](https://github.com/AStarStarship/ASCIICrabs), [CrabsTK](https://github.com/AStarStarship/CrabsTK), and [ScriptTek](https://github.com/AStarStarship/ScriptTek).

### Worlds

1. [GraphWorld](https://github.com/AStarStarship/GraphWorld) - A mathmatical plotting environment.
1. [TileRPGWorld](https://github.com/AStarStarship/iGeekTileRPG) - A role-playing game TileWorld extension.
1. [TileWorld](https://github.com/AStarStarship/iGeekTileWorld) - A 2D tile game engine.
1. [TileCarWorld](https://github.com/AStarStarship/iGeekTileCarWorld) - A TileWorld car autopilot.
1. [PolygonWorld](https://github.com/AStarStarship/iGeekPolygonWorld) - An abstract simulation of viruses.
1. [VirusWorld](https://github.com/AStarStarship/iGeekVirusWorld) - An abstract simulation of viruses.

### Apps

1. [iGeekUlator](https://github.com/AStarStarship/iGeekUlator) - An IMUL graphing Calculator iGeek extension.
